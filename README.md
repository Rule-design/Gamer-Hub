Mobil / Mobile:

🇹🇷 Türkçe:
Gamerhub, oyun hesaplarını takip etmeni, kupa sayını kaydetmeni ve "Kupa Avı" mini oyunuyla eğlenmeni sağlayan tek dosyalık bir web uygulamasıdır; 10 farklı tema, özel profil oluşturma (fotoğraf ve ekran görüntüsü yükleme), başarımlar sistemi, Türkçe/İngilizce/Almanca dil desteği, müzik çalar ve veri yedekleme (Export/Import) gibi özelliklerle birlikte gelir, ayrıca APK olarak indirilip mobil cihazlarda çevrimdışı da çalışabilir. 

Geliştirici: Rule
İndir: En Son Sürüm (v0.44.5)

🇬🇧 English:
Gamerhub is a single-file web app that lets you track your game accounts, save your trophy counts, and have fun with the "Trophy Hunt" mini game; it comes packed with 10 themes, custom profile creation (with photo and screenshot upload), an achievements system, Turkish/English/German language support, a music player, and data backup (Export/Import), and it can also be downloaded as an APK to run offline on mobile devices.

Developer: Rule
Download: Latest Version (v0.44.5) 

🇩🇪 Deutsch:
Gamerhub ist eine Web-App in einer einzigen Datei, mit der du deine Spielkonten verfolgen, deine Trophäenzahl speichern und mit dem Minispiel „Trophäenjagd" Spaß haben kannst; sie bietet 10 verschiedene Themen, die Erstellung eigener Profile (mit Foto- und Screenshot-Upload), ein Erfolgssystem, Unterstützung für Türkisch/Englisch/Deutsch, einen Musikplayer und Datensicherung (Export/Import) und kann auch als APK heruntergeladen werden, um offline auf Mobilgeräten zu laufen.

Entwickler: Rule

💻 PC (Windows)

PC sürümü, uygulama dijital olarak imzalanmadığı için Windows SmartScreen uyarısı verebilir. Çalıştırmak için "Daha fazla bilgi" → **"Yine de çalıştır" seçeneğine tıklayın.

2. `GamerHub.exe` dosyasını çalıştırın

🇬🇧 English:

💻 PC (Windows)

The PC version may trigger a Windows SmartScreen warning because the application is not digitally signed. To run it, simply click "More info" and then "Run anyway".

Installation:
1. Download and extract the ZIP file
2. Run `GamerHub.exe`
3. ⚠️ If you see the "Windows protected your PC" warning, click "More info" → "Run anyway"
